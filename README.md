# 사주 RPG

명리학 사주(四柱)를 기반으로 한 온라인 정통 RPG.

## 지금 해볼 수 있는 것 (첫 맛보기 버전)

캐릭터를 만든 순간의 시각으로 사주팔자가 정해지고, 그 사주가 직업·스탯·전투 상성을 결정합니다.

1. **캐릭터 생성**: "동방 새싹마을로 출발"을 누르는 순간의 시각(연·월·일·시)으로 사주가 확정됩니다. 일간이 직업(60일주 클래스 체계)을 정하고, 오행 점수가 5대 스탯과 보완 오행(용신)을 정합니다. 출발 전까지는 "지금 사주 미리보기 새로고침"으로 몇 번이든 확인할 수 있어, 원하는 사주가 나올 때 출발하는 택일 플레이가 됩니다 — 사주 자체는 확정 순간 하나로만 정해지고 되돌릴 수 없습니다(설계서 3.1).
2. **동방 새싹마을 → 들판 → 신단수 숲**이 하나로 이어진 맵을 캐릭터가 직접 돌아다닙니다. 방향키/WASD(또는 화면 왼쪽 아래 방향 패드)로 이동하고, 오른쪽 아래 오행 버튼(또는 숫자키 1~5, 스페이스로 즉시 공격)으로 실시간 전투를 합니다.
3. **가시멧돼지 사냥** → **천년 신단수 도전**: 들판을 돌아다니는 가시멧돼지는 플레이어를 알아채면 쫓아오고, 가까이 오면 서로 부딪히며 실시간으로 공격을 주고받습니다. 피해량은 오행 상생상극(생·극·설기·비화)으로 정해집니다. 가시멧돼지를 한 마리 이상 잡으면 숲 입구를 막던 문이 열리고, 신단수에게 도전할 수 있습니다. 신단수는 목 기운이 너무 강해 금 공격이 바로 통하지 않으니(목견금결), 화로 먼저 기운을 빼야(설기) 금 공격이 제대로 들어갑니다 — 설계서 6장의 "빼고 친다" 원리를 실시간 상태 변화로 구현했습니다.

모바일 브라우저에서도 세로 화면과 화면 터치 조작(이동 패드 + 오행 버튼)으로 바로 플레이할 수 있게 만들었습니다. 캐릭터·촌장·가시멧돼지·신단수·배경 타일은 Kenney의 무료 CC0 픽셀아트를 사용했습니다(출처는 `CREDITS.md` 참고).

### 단순화한 부분 (다음 단계)

- 사주 분석은 오행 점수·신강·조후·보완 오행까지만 반영했고, 지장간 잠재 스킬·신살 각인·합충에 따른 스탯 보정·대운은 아직 없습니다.
- 전투는 오행 관계(R)와 보완 오행 반응(Y)만 반영했고, 세력비에 따른 반극·과생, 합충 반응(S), 조후 상태(C)는 신단수 전투에 한해 수동으로 흉내만 냈습니다.
- 오행 공격은 사거리 안에서 버튼 한 번으로 즉시 맞는 단순한 판정입니다. 투사체·회피·경직 같은 액션성은 다음 단계로 남겨뒀습니다.
- 동료 NPC, 다른 지역, 아이템은 아직 없습니다.

## 기술 스택

- TypeScript
- [Phaser 3](https://phaser.io/) (브라우저 2D 게임 엔진)
- Vite (개발 서버, 빌드), Vitest (테스트)

## 실행

```bash
npm install
npm run dev    # http://localhost:5173
npm test
npm run build
```

## 구조

- `src/saju/` 사주 계산 (천간, 지지, 오행, 연월일시 네 기둥, 오행 점수·신강·조후·보완오행 분석, 60일주 직업 체계). 게임 화면과 분리된 순수 로직입니다.
- `src/game/` 캐릭터 상태, 전투 피해 계산, 공용 UI 헬퍼.
- `src/data/` 몬스터·보스 정의.
- `src/scenes/` Phaser 게임 화면 (제목 → 캐릭터 생성 → 마을+들판+보스숲을 잇는 실시간 액션 월드).
