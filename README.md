# 사주 RPG

명리학 사주(四柱)를 기반으로 한 온라인 정통 RPG.

## 지금 해볼 수 있는 것

캐릭터를 만든 순간의 시각으로 사주팔자가 정해지고, 그 사주가 직업, 능력치, 전투 상성, 장비 공명을 결정합니다.

1. **캐릭터 생성**: 이름을 정하고 "동방 새싹마을로 출발"을 누르는 순간의 시각으로 사주가 확정됩니다.
2. **새싹마을**: 촌장, 잡화점(복순 할멈), 대장간(무기점), 포목점(옷가게), 수문장, 떠돌이 검객 청솔 등이 있습니다. 가까이 가서 Space(또는 대화 버튼)를 누르면 대화창이 열립니다.
3. **퀘스트**: 메인 퀘스트 3개(도깨비 → 가시멧돼지 → 천년 신단수)와 서브 퀘스트 2개가 있습니다. 머리 위 `!`는 받을 수 있는 퀘스트, `?`는 보고할 퀘스트입니다.
4. **상점**: 사고팔기, 수량 선택, 지금 장비와의 비교(▲▼)를 지원합니다.
5. **장비 = 네 기둥**: 무기는 일주, 옷은 월주, 장신구는 연주, 보조는 시주 자리입니다. 내 보완 오행(용신)과 같은 오행 장비는 공명(★)해서 능력치가 20% 오릅니다. 몬스터가 떨어뜨린 좋은 장비에는 그 몬스터의 일주가 새겨집니다.
6. **전투**: 실시간 액션입니다. 기본 공격과 오행 스킬 5개(덩굴 채찍, 화염구, 바위 방패, 금강참, 생명수)가 있고, 대상에게 유리한 스킬은 초록 테두리, 불리한 스킬은 빨강 테두리로 보입니다. 몬스터마다 스폰 시각으로 정해진 자기 사주와 특수 능력이 있습니다.
7. **천년 신단수 보스**: 목 기운이 넘쳐서 금 공격이 잘 통하지 않습니다. 화로 목기 게이지를 먼저 빼면 약해지고, 그때 금으로 베면 큰 피해가 들어갑니다.
8. **창**: 가방(I), 장비(C), 능력치(P, 레벨업 포인트 분배), 스킬(K), 퀘스트(L), 지도(M), 메뉴(Esc, 저장/제목으로).
9. **저장**: 브라우저에 자동 저장되고, 제목 화면에서 "이어하기"로 계속할 수 있습니다.

모바일 브라우저에서는 세로 화면으로 왼쪽 아래 조이스틱, 오른쪽 아래 공격·스킬·물약 버튼, 맨 아래 메뉴 줄로 플레이합니다.

### 조작

| 동작 | PC | 휴대폰 |
|---|---|---|
| 이동 | 방향키 / WASD | 왼쪽 아래 조이스틱 |
| 공격·대화 | Space | 큰 빨간 버튼 |
| 오행 스킬 | 1~5 | 공격 버튼 둘레 오행 버튼 |
| 물약 | 6 체력, 7 마력 | 오른쪽 작은 물약 버튼 |
| 창 열기 | I C P K L M Esc | 맨 아래 메뉴 줄 |

### 아직 없는 것 (다음 단계)

- 지장간 잠재 스킬, 신살 각인, 합충 반응, 대운은 아직 없습니다.
- 동료 NPC(청솔)는 대화만 있고 아직 합류하지 않습니다.
- 동방 청림 다음 지역과 온라인(다른 플레이어)은 아직 없습니다.

## 기술 스택

- TypeScript
- [Phaser 4](https://phaser.io/) (브라우저 2D 게임 엔진)
- Vite (개발 서버, 빌드), Vitest (테스트)

## 실행

```bash
npm install
npm run dev    # http://localhost:5173
npm test
npm run build
```

## 구조

- `src/saju/` 사주 계산 (천간, 지지, 오행, 연월일시 네 기둥, 오행 점수·신강·조후·보완오행 분석, 60일주 직업 체계). 게임 화면과 분리된 순수 로직입니다.
- `src/data/` 아이템, 상점, 스킬, 몬스터, 퀘스트 정의.
- `src/game/` 게임 진행 상태(레벨, 돈, 가방, 장비, 퀘스트, 저장), 맵, NPC 대화, 전투 피해 계산.
- `src/ui/` 공용 UI 부품(창, 버튼, 게이지)과 가방·장비·능력치·스킬·퀘스트·지도·상점 창.
- `src/scenes/` Phaser 화면: 불러오기 → 제목 → 캐릭터 생성 → 월드(맵, 전투) + UI(HUD, 대화창, 조작 버튼, 창).
